Frontend Developer

Frontend Development is the development of the graphical user interfce of a website, through the use of HTML,CSS, and javascript, so that
users can view and interact with that website.




  • HTML: The Hyper Text Markup Language or HTML is the standard markup language for documents designed to be displayed in a web
    browser.

  • CSS: Cascalling Style Sheets (CSS) is a style sheet language used for describing the presentation of a document written in a markup
    language such as HTML or XML

    1. Pure CSS

    2. Bootstrap (Framework)

    3. Tailwind (Framework)

    4. Saas

  • JavaScript: JavaScript often abbreviated JS, is a programming language that is one of the core technologies of the World Wide Web,
    alongside HTML and CSS. It is use to add functionality in the website.


    1. Vanilla js

    2. JQuery(library)

    3. Reacts

    4. Angular(Framework)
